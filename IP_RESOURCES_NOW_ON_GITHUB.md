## What's NOT Included (Intentionally)

**Excluded to keep repository lightweight:**

| File Type | Reason |
|-----------|--------|
| GDS files | Binary layout files (very large) |
| LEF files | Abstract views (large) |
| .lib files | Timing libraries (large) |
| SPEF files | Parasitic extraction (large) |
| .mag files | Magic layout (binary) |
| Large PNGs | Layout images (>1MB each) |

**Where to get these:**
- Available on server at `/nc/ip/<IP_NAME>/<VERSION>/`
- Generated by OpenLane during PnR
- Not needed for RTL development
